📧 Email

Lets the platform send RFQs, quotes, POs and other emails directly from your domain (e.g. quotes@swiftsitesolutions.co.uk).

Don't have Resend set up yet? It's a quick, one-time process — follow these steps first, then fill in the fields below.
  1. Create an account — sign up at resend.com (free tier is plenty to start).
  2. Verify your domain — Resend gives you a few DNS records (SPF / DKIM). Add them at your domain host (GoDaddy). We can do this part for you if you've already shared GoDaddy access.
  3. Generate an API key — in Resend, go to API Keys → Create, give it a name (e.g. "Stato"), and copy the key. It starts with re_… and is shown only once.

We recommend Resend, but SendGrid or Postmark also work.

Paste the key from your provider. It's encrypted before storage — see the note above.

The address suppliers see. Must be on the domain you verified above.

Optional — e.g. a reply-to address, people to CC, or if you'd like us to handle the DNS verification.

💬 WhatsApp

Lets the platform send WhatsApp messages directly to suppliers via Twilio.

Nothing is blocked while this is set up. For now the platform already opens WhatsApp with the message pre-filled — this just makes sending fully automatic.
  1. Open your Twilio Console — sign in at console.twilio.com.
  2. Copy your Account SID & Auth Token — both are on the Console dashboard under Account Info. The SID starts with AC….
  3. Find your WhatsApp sender number — under Messaging → Senders → WhatsApp senders. If you don't have one yet, we'll help register it (Meta has to approve the WhatsApp Business sender — that can take a little time).

Starts with AC followed by a long string.

Treat this like a password. It's encrypted before storage.

In full international format, e.g. +44 7700 900123.

Optional — e.g. if you still need a sender registered, or a display name for the business profile.

⏳ WhatsApp goes live once the WhatsApp Business sender has been approved by Meta. We'll keep you posted on that.
