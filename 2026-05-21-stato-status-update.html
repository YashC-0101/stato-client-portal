Fix 2 — OCT-36: traffic-source schema accepts accountIds[]

Backend change. Migration 0030 added a JSON array column so one traffic-source row can union spend from multiple Catchr accounts on the same platform (Solar Panels UK pulling from 4 Facebook accounts at once).
